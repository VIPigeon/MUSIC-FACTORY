
## Как запустить
1. клонируй репозиторий
2. В репозитории валяется два исполняемых файл tic80 и tic80.exe (для линукса и винды соответственно)
3. С помощью исполняемого файла запустите файл MUSIC-FACTORY.tic

## Как играть
Бро, просто используй стрелочки

## Для тестировщиков
1. У игры нет концовки в текущей версии. Планируется небольшое изменение мелодии с требованием выжить определенное количество времени
2. Игра должна выглядеть законченной. Если что-то не к месту или наоборот, чего-то явно не хватает, укажите на это
