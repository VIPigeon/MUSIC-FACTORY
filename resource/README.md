Если ресурс используется только одной сценой (например спрайт игрока), то положите этот ресурс рядом со сценой. Об этом ещё написано в [доке](docs/architecture.md).

Если же есть ресурс, который используется несколькими сценами, или который непонятно как 
категоризовать, то можно закинуть его сюда. Всё равно строгих правил нет :)
